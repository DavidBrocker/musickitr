# musickitr: Tidy Access to the Apple Music API

Provides tidy, tibble-based access to the Apple Music Catalog API
(search, charts, artists, albums, songs) plus a few similarity utilities
useful for building music recommendation and matchup tools. Users must
bring their own MusicKit developer credentials (Team ID, Key ID, and
private key) from an active Apple Developer Program membership.
